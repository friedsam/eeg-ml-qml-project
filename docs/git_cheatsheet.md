# Git + GitHub Cheatsheet

## 1. Check status
```bash
git status
```

## 2. Stage files
```bash
git add filename.py    # Add one file
git add .              # Add all changed files
```

## 3. Commit changes
```bash
git commit -m "Describe what you did"
```

## 4. Push to GitHub
```bash
git push               # If already connected to origin/main
git push origin main   # First push
```

## 5. Pull updates
```bash
git pull
```

## 6. Check remote
```bash
git remote -v
```
